# Qwen3-TTS 网页朗读扩展

## 1. 启动本地语音服务

在 Apple Silicon Mac 上双击 `启动Qwen朗读服务.command`。看到下面的信息后保持
终端窗口开启：

```text
本地语音服务：http://127.0.0.1:8765/
```

端口会先开放，模型随后在后台预热；因此扩展不会在启动阶段直接显示
`Failed to fetch`。如果 MLX 进程异常退出，启动窗口会自动重启服务。

首次运行会通过 MLX Audio 独立下载 Qwen3-TTS 模型，不要求安装 PDFgear，也不
读取 PDFgear 的文件。服务只监听本机地址，网页文字和生成的音频不会离开电脑。

正式发布包另含 Windows、macOS、Linux 各自的启动器和安装说明；可运行
`uv run python scripts/package_extension.py` 在 `dist/` 生成三份 ZIP。

## 2. 加载扩展

1. 在 Chrome 地址栏打开 `chrome://extensions`。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择此目录：
   `/Users/conermoltbot/Documents/pdf-book-site/browser-extension`

安装后建议把扩展固定在工具栏。点击扩展图标可以检查本地服务状态。

如果此前已经加载过本扩展，更新代码后请在 `chrome://extensions` 的扩展卡片上
点击“重新加载”，并刷新正在阅读的网页。

## 3. 使用

1. 打开任意普通 HTTP 或 HTTPS 网页。
2. 选择一段正文。
3. 点击“朗读选中”或“从此处连续朗读”。
4. 连续朗读时：
   - Space：暂停或继续
   - Esc：停止
   - 浮动播放器可以调速、暂停和停止

正在朗读的句子会自动高亮并滚动到页面中央。

暂停超过 30 秒后仍可按 Space 恢复。Chrome 如果已经回收静默的音频页面，扩展
会从当前句重新生成，并继续剩余队列。

若提示无法连接本地语音服务，请确认启动窗口仍在；扩展会先自动进行有限次数的
重连，不再直接显示浏览器原始的 `Failed to fetch`。

## 限制

- Chrome 不允许扩展注入 `chrome://`、Chrome 网上应用店等受保护页面。
- 安装后已经打开的网页需要刷新一次。
- 跨域 iframe、翻页后的下一篇文章和浏览器内置 PDF 阅读器暂不连续读取。
- `file://` 页面需要在扩展详情中手动开启“允许访问文件网址”。
