# Qwen3-TTS 网页朗读扩展

## 1. 启动本地语音服务

双击 `启动Qwen朗读服务.command`。看到下面的信息后保持终端窗口开启：

```text
本地语音服务：http://127.0.0.1:8765/
```

服务只监听本机地址，复用 PDFgear 已下载的 Qwen3-TTS 模型。网页文字和
生成的音频不会离开这台电脑。

## 2. 加载扩展

1. 在 Chrome 地址栏打开 `chrome://extensions`。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择此目录：
   `/Users/conermoltbot/Documents/pdf-book-site/browser-extension`

安装后建议把扩展固定在工具栏。点击扩展图标可以检查本地服务状态。

如果此前已经加载过本扩展，更新代码后请在 `chrome://extensions` 的扩展卡片上
点击“重新加载”，并刷新正在阅读的网页。

## 3. 使用

1. 打开任意普通 HTTP 或 HTTPS 网页。
2. 选择一段正文。
3. 点击“朗读选中”或“从此处连续朗读”。
4. 连续朗读时：
   - Space：暂停或继续
   - Esc：停止
   - 浮动播放器可以调速、暂停和停止

正在朗读的句子会自动高亮并滚动到页面中央。

## 限制

- Chrome 不允许扩展注入 `chrome://`、Chrome 网上应用店等受保护页面。
- 安装后已经打开的网页需要刷新一次。
- 跨域 iframe、翻页后的下一篇文章和浏览器内置 PDF 阅读器暂不连续读取。
- `file://` 页面需要在扩展详情中手动开启“允许访问文件网址”。
